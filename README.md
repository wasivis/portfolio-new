# wasivis — Personal Portfolio

Personal portfolio website showcasing my work as a full-stack developer.

## Live Site

https://wasivis.vercel.app/

## Built With

- Next.js
- TypeScript
- Tailwind CSS
- Vercel

## Features

- Responsive single-page portfolio
- Project showcase with live demos and GitHub repositories
- About / skills section
- Contact section
- Responsive navigation

## Getting Started

npm install
npm run dev
